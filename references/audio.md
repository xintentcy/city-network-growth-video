# 解说、配乐与混音

成片是"解说主导 + 音乐托底"的结构：音乐负责情绪和节奏感，解说负责信息，
两者必须**错开频段和起落点**，否则再好的画面也会显得吵。

## 1. 解说

- 引擎：`edge-tts`（免费、中文自然），音色 `zh-CN-YunyangNeural`，语速 `-6%`
  （纪录片语速；`+0%` 会赶，`-10%` 会拖）
- 每章单独合成、单独 loudnorm，**不要**整片合成后再切，否则切点会带气口
- 后处理链（顺序不能换）：

```
highpass=f=80, loudnorm=I=-17:TP=-3:LRA=9, treble=g=-2:f=6800:width_type=o:width=1.6
```

`highpass 80` 去掉 TTS 的低频嗡声；`loudnorm -17` 统一每章响度；
`treble -2 @6.8k` 压掉齿音，中文 TTS 的"嘶"很容易在 6–8 kHz 扎耳。

- 导出 48 kHz 单声道 wav；时长写进 `data/voice.json`，时间轴直接用这个值

## 2. 配乐（程序化，不采样）

用 numpy 现场合成，好处是：长度天然等于视频长度（**不存在循环断点**），
段落能量可以精确跟着线网规模走。

### 调性选择

| | 旧版（闷） | 新版（轻快明亮） |
|---|---|---|
| 调性 | A 小调 | **D 大调** |
| 速度 | 84 BPM | **112 BPM** |
| 和声 | Am–F–C–G | **D–A–Bm–G（I–V–vi–IV）** |
| 主织体 | 长 pad + 稀疏琶音 | **马林巴八分琶音** |
| 高频 | 几乎没有 | 钟琴点缀（隔一个音） |

改完之后频段分布从「55% 挤在 125 Hz 以下、1 kHz 以上为零」变成
「35% 低频 / 45% 中频 / 6% 中高 / 2% 高频」，听感从"闷"变成"亮"。

### 配器与写法

- **马林巴**：`sin + 0.26·sin(4f) + 0.10·sin(9f)`，衰减 `exp(-5.4t)`，
  起音 3 ms。用**中音区本体**（4 度音域，D4–A4）
- **钟琴 sparkle**：琶音 +12 度，隔一个八分音符一次，`amp≈0.03`，只负责"亮"
- **铺底**：三个微失谐正弦（±0.3%），慢起 0.55 s，只做和声胶水
- **贝斯**：根音 1 拍 + 3 拍 + 3.5 拍八度过门，`sin + 0.30·sin(2f)`（2 次谐波给 146 Hz 的厚度）
- **打击**：轻 kick 落 1、2.5 拍；八分沙锤（强拍 1.0 / 弱拍 0.62）；
  拍手只在 `lineCount/17 > 0.55` 之后进（约 2020 年）
- **旋律**：16 小节一乐句，前 8 小节主题、后 8 小节变奏或留白——
  留白是给解说的，不要每小节都塞旋律

### 能量曲线

按"已开通线路数"映射，逐层加入：

```python
open_g = nLines(t) / nTotal
pad_g  = 0.42 + 0.58*bump(open_g)
arp_g  = 0.66 + 0.34*bump(open_g, 0.05, 3.0)
per_g  = 0.30 + 0.70*bump(open_g, 0.10, 4.0)
clap_g = bump(open_g, 0.55, 9.0)
```
开头 2.5 s `^1.25` 渐入、末 6 s 逐层退出 + 1.2 s 硬淡出。

## 3. 混音

```
BGM × BGM_GAIN(0.20) × duck  +  解说  →  tanh 软限幅  →  归一化到 0.92
```

- **ducking**：把解说包络做 20 ms + 120 ms 两级平滑，`duck = 1 - 0.45*clip(env*2.6,0,1)`，
  解说一出声 BGM 掉 45%（约 -5 dB），句间自动回来
- **配比**：混完打印 `nar_rms / bgm_rms`。经验值 **BGM 比解说低 10–12 dB**：
  - 偏氛围（旧版）9.3 dB 就够
  - 明亮律动型（新版）要 11.8 dB，因为瞬态更抢注意力
- **母带**：`tanh(mix*1.15)/1.15` → 归一到 0.94 → `tanh(*1.02)*0.955` → 0.92。
  实测成片 Integrated ≈ **-12.9 LUFS**、TP ≈ -0.6 dBTP，适合网络投放

## 4. 响度对齐的坑

- **不要用 RMS 判断 BGM 是否"一样响"**。打击乐型 crest factor 大：
  新曲 RMS 0.082 vs 旧曲 0.159（差 5.7 dB），但 LUFS 只差 4.4 dB。
  统一用 `ffmpeg -af loudnorm=print_format=summary` 看 **Integrated LUFS**
- **不要用频谱重心判断"亮不亮"**。重心会被高频 bin 数量带偏，
  实测 5.8–6.7 kHz 是假象；看**八度频段占比**才准
- **判断削波要逐样点算**：解码成 `f32le` 后取 `max(abs(x))`。
  `volumedetect` 的正则解析会给出假峰值（曾误报 peak 1.30，实际 0.923）

## 5. 时长匹配

`mix.wav` 长度 = 场景 `total`；视频比音频长 15 ms 属正常（`-shortest` 以视频为准）。
封装时用 `-c:v copy`，不要重编码画面——省 40 分钟，也保证画面一个像素都没动。
