# 数据管线与场景 JSON

## 0. 事实纪律（先读这一条）

这类片子唯一的护城河是**数据不编**。AI 生成视频会顺手编线路走向和站名，
所以整条链路必须是：真实几何（OSM）+ 真实开通日期（官方发布）+ 官方里程锚点。

- 几何：OpenStreetMap（ODbL，片尾必须标注）
- 开通日期 / 起止站：轨道集团/地铁公司官网、当地党媒报道
- 里程：官方"运营里程"口径，至少 3 个锚点；**不要**拿几何长度当里程用

正文数字必须和画面 KPI 一致。口径拿不准就写"六百七十多公里"这种模糊说法，
并在片尾注明"数据截至 YYYY.MM"。

## 1. 抓几何

```bash
python fetch_network.py --network 成都地铁 --boundary 成都市 \
    --bbox 30.0,103.4,31.35,104.75 \
    --rings 一环路,二环路,成都三环路,成都绕城高速
```

要点：

- **必须带 User-Agent**，否则 overpass-api.de 直接 406
- 查询用 POST 表单 `data=<QL>`，`[out:json][timeout:300]`
- 公共实例不稳定（502 / 读超时很常见）。脚本单请求 90 s、2 轮重试、3 个端点轮询；
  仍失败就去 overpass-turbo.eu 导出，存成 `data/routes_geom.json` + `data/stop_names.json`，
  再用 `--skip-fetch` 走离线编译（`compile_lines()` 与联网路径完全同一套逻辑）
- `rel["route"="subway"]["network"="成都地铁"]` 比按区域抓更干净；network 名称先用
  `rel["route"="subway"](bbox)` 探一次看实际标签
- 边界：`rel["boundary"="administrative"]["name"="成都市"]`
- 环线：一环/二环/绕城多为 `relation`（name 标签命中），三环常只有 `way` 集合，
  脚本对两者都做了兼容（relation 取 way 成员几何，way 直接取）

## 2. lines.json 结构

```jsonc
{
  "1": {
    "ref": "1",
    "tracks": [{
      "terminals": ["升仙湖", "科学城"],      // 起终点站名
      "color": "#0F6CB6",                     // OSM colour 标签
      "points": [[lon, lat], ...],            // 串接好的折线
      "km": 41.0,                             // 几何长度（不是官方里程）
      "stops": [{"name": "升仙湖", "lon": .., "lat": ..,
                 "t": 0.0, "d": 0.0}]          // t=归一化里程(0-1), d=米
    }]
  }
}
```

清洗规则（`fetch_network.py` 已实现）：

| 脏数据 | 处理 |
|---|---|
| 同一 ref 有上下行 / 区间车多个 relation | 按首末站对分组，取站数最多的 |
| 短交路（站集被主线包含） | 剔除 |
| `name` 含"快线/直达/联络" | 跳过（不是正线） |
| 没有 `ref` 标签的线路 | 从 name 里提取编号兜底，人工复核 |
| 站名节点无 name | 回落到 `node<id>`，需人工补 |
| 关系把"共线/贯通段"算进本条线（如成都 19 号线含 18 号线天府站—天府机场北） | 写进 `config.DROP_TRACKS`，整条关系剔除，否则里程与站序都会多一截 |
| 同 ref 有"主线"与"含支线整线"两条关系 | 事件优先匹配站数最多的超集；无事件的重复关系自动丢弃 |

## 3. openings.csv（全片的事实骨架）

```csv
date,ref,from,to,hint
2010-09-27,1,升仙湖,世纪城,科学城
2017-12-06,7,崔家店,崔家店,崔家店
```

- `from/to` 必须是该轨道上的真实站名，**顺序即开通方向**
- 环线成环（首末同一站）用 `from=to`，脚本按整条线（t0=0, t1=1）处理
- `hint`：同 ref 多条轨道时用来指认主线，填该轨道任一独有站
- 一次公告开多段就写多行，同一日期多行会合并进同一章

`build_openings.py` 会打印覆盖度：

```
ok 1 升仙湖→科学城 cover=1.00 segs=4 gaps=[]
!! 19 金星→天府站  cover=0.83 segs=2 gaps=[(0.62,0.79)]
```
`cover<0.92` 或有 `gaps` 说明你漏了某次开通公告，必须补齐再往下走——
否则画面上会有一条线"断在半路"。

## 4. scene2.json（渲染器的唯一输入）

```jsonc
{
  "W":1920,"H":1080,"fps":30,"total":192.452,
  "view":[1238,516,1320,1080],        // 地图视口 x,y,w,h
  "mapLeft":600,                       // HUD 安全边界
  "tracks":[{
     "ti":0,"ref":"1","color":"#0F6CB6","km":41.0,
     "pts":[[x,y]...],                 // 已投影到 km 坐标（不是经纬度）
     "cum":[0,0.31,...],               // 每点累计里程
     "stops":[{"n":"升仙湖","t":0.0,"x":..,"y":..}],
     "segs":[{"t0":0.0,"t1":0.13,"date":"2010-09-27",
              "tA":11.0,"dur":0.86,"km":18.1}]
  }],
  "rings":{"一环":[[[x,y]...],...]},
  "ringOrder":["绕城","三环","二环","一环"],
  "ringC":{"二环":[x,y]},              // 各环中心，用于构图配重
  "chapters":[{"id":"2010-09-27","date":"2010-09-27","title":"2010.09.27",
               "chips":[["1","升仙湖—世纪城"]],"cn":"...","en":"...",
               "tA":11.0,"nA":11.4,"nDur":8.2,"tE":21.08,
               "cum":18,"nLines":1}],
  "cams":[{"t0":11.0,"t1":12.5,"from":[span,cx,cy],"to":[...]}],
  "anch":[[17.52,18.5],[511.14,558.0],[705.29,716.0]],
  "nLinesTotal":17,"kmTotal":716.0
}
```

`chips` 是 `(线路 ref, "首站—末站")`，同时驱动 HUD 徽标、主角线判定、行进方向。

## 5. 投影

局部等距投影，原点放市中心：

```python
KX = cos(radians(LAT0)) * 111.32     # km / 经度
KY = 110.54                          # km / 纬度
x = (lon - LON0) * KX
y = -(lat - LAT0) * KY               # y 轴朝下
```
城市尺度（<100 km）用这个足够，误差 <0.3%，比引 pyproj 省事。

## 6. 里程锚定（关键）

几何长度 ≠ 官方运营里程：换乘站重复计算、支线计法、四舍五入都不同。
所以按官方锚点做分段线性映射：

```python
ANCH = [(cum_geo(t_2010), 18.5), (cum_geo(t_2020), 558.0), (cum_geo(t_2025), 716.0)]

def disp_km(g):
    for (g0,v0),(g1,v1) in zip(ANCH, ANCH[1:]):
        if g <= g1: return v0 + (v1-v0)*(g-g0)/(g1-g0)
```
`cum_geo` 必须用**渲染时的同一个 `seg_prog`** 累加，否则 KPI 和画面生长不同步
（画面上线没长完，里程已经跳了）。

## 7. 环线

真实环线是"城市参照物"，不是装饰：观众靠它判断"这条线出没出圈"。

- 环名必须和 `config.RING_ORDER` 一致（由外到内：绕城 → 三环 → 二环 → 一环）
- 透明度外淡内实（128/146/160/176），否则外圈抢戏
- 讲"出圈/成环/越过绕城"的章节用 `RING_HI` 高亮对应环线（α→104 的描边 + 标签加亮）
- 环线标签会随缩放淡出（`LIM`：一环 span>56 淡、二环>72、三环>96），
  推近时只留内环，避免一堆文字压在线上
