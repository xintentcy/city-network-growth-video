# 验收清单

分三类：**事实**（能不能播）、**技术**（有没有硬伤）、**观感**（是不是专业）。
每条都给了可执行的判断方式，不要靠"看起来还行"。

## A. 事实（最高优先级）

- [ ] 每个开通日期都能指到来源（官网/党媒），不止一处出处交叉
- [ ] 起止站名与官方公告一致（含"站"字的有无）
- [ ] 官方运营里程至少 3 个锚点，KPI 与锚点吻合
- [ ] 文案里出现的数字（条数/里程/站数）与画面 KPI 一致
- [ ] 未开通车站已剔除（`EXCLUDE_STATIONS`），不能在片中出现
- [ ] 片尾注明：数据截至时间、几何来源（OSM ODbL）、里程为估算口径
- [ ] 没有"最大/首个/唯一"等绝对化表述没有出处

> 有个真实例子：曾把 2025-09-17 写成"破 700 公里"，但该时点模型值是 671 km，
> 破 700 实际发生在 2025-12-16。这类错误只能靠"文案数字 ↔ 画面 KPI ↔ 官方"三方对齐发现。

## B. 技术

一条命令跑完：

```bash
python verify.py out/成片.mp4
```

期望输出全 ✅：

| 检查 | 判据 |
|---|---|
| 分辨率 / 帧率 | 目标值，30/1 |
| 帧数 | 与无音轨母版一致（±0.5 s） |
| 无削波 | 峰值 ≤ 1.000，`>1.0` 样点数 = 0 |
| 音画等长 | 差 < 0.6 s |
| 整体响度 | -16 ~ -11 LUFS（投放建议 -14 ~ -12） |
| 真峰值 | ≤ -0.2 dBTP |
| 片头渐入 / 片尾收束 | 首 2 s 上升、末 2 s 下降，无硬切 |
| 跨段无跳帧 | 相邻段接缝帧差 ≤ 3.5（章节切换处的正常跳变可到 5，需人工确认） |
| 无长时间静帧 | 抽样 12 点，帧差 > 0.4 |

额外手工确认：

- [ ] 只换音频时，视频流 MD5 与母版**完全一致**（`-c:v copy` 后核对）
- [ ] 抽帧看 6 个关键节点：片头、首章、最密章节、环线成环、最长线、片尾
- [ ] 密集章节站名重叠 ≤3 处，且不压住当前站标签

## C. 观感（动效专项）

- [ ] 每章都能看出"推近 → 行进 → 停顿 → 拉远"四拍，节奏一致
- [ ] 章首**不是空镜**：虚影走廊 + 空环预告已在位
- [ ] 光点到达某站时，站点在同一帧点亮（差 1–2 帧可接受，差 0.2 s 就不行）
- [ ] 反向线路（跨市线、编号大且由外向内）方向与标注一致
- [ ] 里程读数随光点单调增，不会在反向章节倒跳
- [ ] 站名不压线路、不压环线标签、不出安全区
- [ ] 环线只做背景：不抢主线亮度，讲"出圈"时才高亮
- [ ] 字幕不出画、不压遮罩边缘、末行不是孤字
- [ ] 音乐在解说句间有起伏，但**听不清旋律也不影响理解**（说明配比对了）

## D. 交付物

```
out/
├ 成片.mp4          视频 + 混音，faststart
├ cover.png         从成片抽帧，不要另做
└ (可选) bgm.wav    纯配乐，方便 A/B
```
渲染中间帧（`p_*.png`）、分段（`segs/`）、补丁脚本在交付前清掉，
只留成片、封面和可复跑的脚本。
