# 视觉系统

整体是"深色控制台 + 编辑式左栏"：左边念数据，右边看地图，底部说人话。
不要做成"数据大屏"（满屏 KPI 卡片），这是一个有解说的短片，信息要有主次。

## 1. 版式栅格

```
1920 × 1080
├ 左栏 HUD   x: 96 – 636   （宽 540，右边距 636）
└ 地图视口    x: 1238 起，1320 × 1080（超出画布的右侧被裁掉，留出"地图延伸感"）
   底部字幕   y: 932 – 1046
```

- 左栏安全边界 `mapLeft=600`：地图元素（站名、环线标签）不越界
- 站名避让的硬边界 `x∈[596,1886], y∈[68,896]`
- 底部 240 px 是字幕区，加梯度遮罩（`238*(i/239)^0.72`），不放任何地图元素

## 2. 字号层级（Inter/Deng + 微软雅黑混排）

| 用途 | 字体 | 字号 | 说明 |
|---|---|---|---|
| 大日期 | Deng | 84 | 等宽数字，`0.5` 字距 |
| 片头标题 | 雅黑 Light | 66 | `3.0` 字距 |
| KPI 数字 | Deng | 40 / 30 | 右对齐，带单位 |
| 中文解说 | 雅黑 | 36 | 行高 50 |
| 章节标题 | 雅黑 Light | 60 | 非日期章（片头/片尾） |
| 线路标签 | 雅黑 | 17 | |
| 英文字幕 | Segoe UI | 16 | 行高 24，透明度 0.82 |
| 脚注/口径 | 雅黑 | 11 | 透明度 0.5–0.6 |

数字统一用 Deng（等宽，跳动不抖），中文用雅黑。英文**不要**用雅黑——雅黑的西文
撇号和字距会撑出空隙，必须 Segoe UI。

## 3. 配色

- 底色：中心 `rgb(12,20,35)` → 外圈 `rgb(3,5,9)` 径向渐变，叠 70 px 网格（+6,11,19）
- 线路色：取 OSM `colour` 后做 HSL 提亮（`s ≥ 0.66`, `l ≥ 0.64`），
  保证深色底上都能看清，同时保住官方色的辨识度
- 环线：`rgb(146,168,198)`，alpha 128/146/160/176（外淡内实）
- 文字：主 `rgb(240,246,255)`，次 `rgb(178,199,227)`，辅助 `rgb(128,158,198)`
- 光晕：整体 `GaussianBlur(12)` 后 `×1.62` 再叠加，只做一层，不要叠多层

## 4. 中文折行（必须做，否则一眼业余）

按像素宽折行，且满足四条：

1. **行首不留标点**：`，。、；：！？）」』】` 等若落在行首，把上一行末字一起带下去
2. **末行不留孤字**：末行去掉标点后 <4 字，从上一行回拉
3. **中文数字不断开**：「六百 / 七十」这种必须并到下一行
4. **单行宽 ≤944 px**（36 px 字号，约 26 字）

英文按**词**折行（`s.split(' ')` 逐个试宽），不要按字符折——
按字符会把 `Chengdu` 切成 `Cheng / du`。

## 5. 字幕区

- 中文：`x=96`，`y=948` 起，行高 50，白色 250 alpha
- 英文：`x=1064`，`y=952` 起，行高 24，`rgb(158,192,234)` 0.82 alpha + 1px 暗影
- 中间 1px 竖线 `x=1030`，alpha 26，做中英分隔
- 进场：0.55 s 上浮 12 px + 淡入；出场 0.4 s 淡出
- **遮罩必须压在字幕下面、地图上面**：顺序错了地图亮线会穿过字

## 6. HUD 元素顺序（从上到下）

1. 品牌：`成都地铁 · 十五年` + 英文副标
2. 大日期 / 章节标题
3. 线路徽标（芯片）+ 一句"发生了什么"
4. 年份轴（2010–2025，5 年一档刻度 + 游标）
5. 数据表：开通线路 / 运营里程 / 数据截至
6. 口径两行（11 px，低调但不能省）
7. 线路清单（9 列 × 2 行徽标，未开通的只有描边）

右上：环线图例（两行）。右下：版权与数据来源。
片尾单独做全屏收束：模糊 + 压暗 84%，居中一句总结 + 三个数字 + 来源。

## 7. 封面

从成片里挑一帧，不要另做。优选"信息量与辨识度同时最高"的那一帧：
本例用了 2017-12-06 环线成环（白环落在二环与三环之间，沿途站名清晰），
比"全网图"更适合做缩略图——全网图在 320px 宽时全是噪点。
